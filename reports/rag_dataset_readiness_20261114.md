# RAG 데이터셋 실사용 최종 점검

확인일: 2026-11-14

## 결론

- 1차 적재 추천: 삼국사기 1개
- 다음 확장 후보: 공식 상세 페이지에서 제1유형과 인공지능 학습용 표시를 직접 확인한 22개
- 보류: 조선소요사건관계서류 1개, 제한 4개, 추가 확인 필요 18개

외부 업로드는 아직 수행하지 않았다.

## 근거 수준 재분류

### A. 공식 상세 페이지와 기계판독 카탈로그에서 직접 확인(13개)

고려사, 국외항일운동자료, 반민특위조사기록, 삼일운동DB 경찰탄압기구·격문·출처정보,
유엔 한국문제 미국무부문서, 일제침략하 한국36년사, 조선시대 법령자료,
한국고대금석문, 한국근현대인물자료, 한민족독립운동사자료집, 고도서 메타데이터.

이 자료들은 개별 데이터셋의 공공데이터포털 상세 페이지와 `catalog/.../fileData.json`에서
제1유형·AI 학습용 표시를 확인했다.

### B. 공식 데이터셋 상세 페이지에서 직접 확인, 일반 공공누리 증서로 조건 보충(10개)

조선왕조실록 인물·실록원문, 고종시대사, 삼국사기, 삼국유사,
삼일운동DB 군대탄압기구, 자료대한민국사, 한국근대사자료집성,
한국사연구휘보, 한국역사용어시소러스.

이 자료들도 개별 상세 페이지 자체에 제1유형·AI 학습용이 표시되어 있다. 대장에 연결한
일반 공공누리 페이지는 제1유형의 세부 의무를 설명하기 위한 보조 근거이지, 라이선스 판정의
유일한 근거가 아니다.

### C. 일반 제1유형 해석만으로 분류했던 항목(1개) - 적재 보류

조선소요사건관계서류는 상세 페이지가 제1유형이지만 AI 학습용 표시가 없고, 확인된 공식
페이지의 파일 버전(2022-05-10)과 보유 파일(2026-08-11)이 다르다. 최종 적재 후보에서
제외하고 제공기관 확인 대상으로 이동한다.

## 제1유형과 AI유형 적용

| 작업 | 제1유형 의무 | AI 학습용 추가 의무 | 시스템 반영 |
|---|---|---|---|
| 임베딩 | 출처표시, 저작인격권 존중 | 동일·실질 유사 산출 방지 | AI 직접 표시와 상세 URL 없으면 적재 차단 |
| Pinecone 저장 | 변경·공유 허용 범위 준수 | 파생 학습데이터 재판매 금지 | 권한 상태·기관·데이터셋·공식 URL·라이선스 저장 |
| LLM 전송 | 합법적 이용권한 확보 | 직접 인용 시 출처표시 기술 조치 | 답변 인용을 원문과 문자열 대조 |
| 사료 직접 인용 | 기관명·자료명·링크 표시 | 직접 인용의 출처가 보이도록 조치 | Streamlit 인용문 아래 출처 문구와 공식 링크 표시 |

OpenAI API는 기본적으로 입력·출력을 모델 학습에 사용하지 않지만 일반 API는 남용 모니터링
목적으로 최대 30일 보관될 수 있다. Pinecone은 고객이 제출 자료에 필요한 권리를 확보할
책임이 있다고 명시한다. 따라서 공공누리 허용과 별도로 계정의 데이터 공유 설정, 보존 기간,
저장 리전과 삭제 절차를 확인해야 한다.

## 코드 준비 상태

- 외부 적재 전 `rights_status=conditional_allowed` 확인
- `ai_training_marking=explicit` 확인
- 공공데이터포털 상세 URL과 권한 근거 URL의 일치 확인
- 기관명·데이터셋명·라이선스·확인일 누락 시 적재 중단
- Streamlit에서 직접 인용문, 기관명, 데이터셋명, 라이선스, 공식 URL 표시
- 삼국사기 4,622건을 권한 메타데이터가 포함된 새 JSONL로 준비
- 문서 자체 메타데이터와 최종 권한 대장을 적재 직전에 교차 확인
- 권한 대장에 조건부 허용·AI 명시·동일 공식 URL이 없으면 Pinecone 연결 전에 중단

- 승인 플래그가 없는 적재 명령의 외부 전송 차단 확인

## 추가 확인 필요 18개와 공식 문의 항목

| 사유 | 데이터셋 | 문의할 사항 |
|---|---|---|
| 공식 조건 충돌 | 고려사절요, 친일파관련문헌, 한국독립운동사자료, 한국사료총서 | 구조화된 제1유형·AI 표시와 비상업·변경금지 설명 중 어느 조건이 우선하는가 |
| 버전 불일치·충돌 | 삼일운동DB 세부장소, 도장관 보고철, 중추원조사자료 | 보유한 2026년 파일에 적용되는 정확한 라이선스와 AI 이용 가능 여부 |
| 개별 라이선스 부재 | 역사지리 메타정보, 임시정부자료집, 비변사등록, 삼일운동DB 헌병·사건정보, 원고려기사, 경성지방법원 해제, 한국근대사기초자료집 | 해당 파일의 공공누리 유형, AI 표시, 외부 API 전송·벡터 저장 가능 여부 |
| 복합 원권리 | 일본군 위안부 전쟁범죄 자료집, 동아시아 고대문화유산 사전, 한국학중앙연구원 주제어 사전 | 원문·번역·이미지·개별 항목의 제3자 권리와 일괄 AI 활용 가능 여부 |

모든 문의에는 다음을 구체적으로 적어야 한다: OpenAI 임베딩/LLM API로 원문 일부를 전송하는
행위, Pinecone 해외 클라우드에 원문 청크·벡터·메타데이터를 저장하는 행위, 검색 결과에서
짧은 원문을 직접 인용하는 행위, 비상업적 수업 시연이라는 이용 목적.
