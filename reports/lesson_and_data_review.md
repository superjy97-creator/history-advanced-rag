# 수업 요구사항 및 데이터 검토

검토일: 2026-11-14

## 교안에서 확인한 필수 구현 기준

교안 276~285쪽은 Advanced RAG를 다음 네 단계로 분리하여 실제로 연결하도록 설명한다.

1. 질의 변환: 탈맥락화, 복합 질의의 최대 3개 분해, 용어 확장. 고유명사·날짜·번호를
   보존하고 JSON 배열로 출력한다.
2. 리랭킹: 벡터 검색 상위 8~20건을 질문과 함께 다시 평가한다. 직접 답을 포함할 때만
   yes로 판정하고 원문 evidence를 반환한다. 0건이면 생성하지 않고 거절한다.
3. 생성: 컨텍스트만 사용하고, 상충 처리·고정 인용 형식·근거 부족 시 행동·출력 형식을
   명시한다.
4. 검증: 생성과 분리된 호출에서 답변을 원자적 주장으로 나누고, 원문 quote가 있는
   주장만 지원된 것으로 판정한다. 지원되지 않은 주장은 수정본에서 제거한다.

교안 244~270쪽의 Pinecone·소득세법 코드는 개념과 API 사용을 보여 주는 참고 예제다.
예제의 데이터셋, 모델명, 1,500자 청크, 300자 중첩, 차원 3,072는 역사 사료 시스템의
고정 과제 조건이 아니다. Pinecone을 실제 클라우드 벡터 DB로 사용하는 점은 본 과제에
적용한다.

## 프로젝트 목표와의 충돌

네 단계, 근거 제한, 인용 및 검증, Pinecone 사용은 프로젝트 목표와 충돌하지 않는다.
교안은 일반 정책문서 예시이므로 `effective_date`, 조항 우선순위 같은 규칙은 역사 사료에
그대로 강제하지 않고 문헌명·기사 ID·시대·원문 구분·공식 URL을 보존한다.

## 현재 구현·검증 상태

- 삼국사기 사료 4,622건을 원본 ZIP 변경 없이 JSONL로 변환
- 질의 변환 → Pinecone 검색 → 리랭킹 → 생성 → 별도 검증 파이프라인 구현
- 원문에 존재하지 않는 인용문을 차단하는 결정적 검증 추가
- Streamlit 화면과 단계별 실행 기록 표시 구현
- 로컬 단위 테스트 3개 통과, 모듈 컴파일 및 Streamlit 기동 확인
- 외부 전송과 유료 API 호출은 아직 수행하지 않음

## 실습 노트북 및 환경 교차 검증

- 실습 노트북은 Pinecone 적재·검색을 포함한 기본 RAG 예제이며, 질의 변환·리랭킹·별도
  검증은 구현하지 않는다. 이 세부 기준은 PDF 276~285쪽을 따른다.
- 실습 환경은 Pinecone 7.x와 `langchain-pinecone 0.2.13` 조합이다. 현재 가상환경에는
  Pinecone 10.3.0이 설치되어 있어 하향 설치하지 않고 최신 SDK를 직접 사용한다.
- 새 패키지를 설치하지 않고 설치되어 있던 `langchain-openai 1.7.4`의 `ChatOpenAI`와
  `OpenAIEmbeddings`를 적용했다.
- DOCX·Chroma 예제용 `docx2txt`, `sentence-transformers`, `langchain-pinecone`은 현재
  역사 RAG 실행에 필요하지 않아 설치하지 않았다.
- Pinecone 인덱스의 차원(1,536)·거리 함수(cosine)·준비 상태를 확인하고, 적재 후 실제
  네임스페이스 레코드 수가 요청 건수 이상인지 검증하도록 보완했다.
- 리랭킹 통과 결과가 0건이면 생성·검증 API를 호출하지 않고 교안의 고정 거절 문구를
  반환한다.

## 외부 전송 전 권한 및 예상 비용

- 공식 공공데이터포털은 삼국사기 원문을 공공누리 제1유형(출처표시) 및 인공지능
  학습용으로 표시한다: https://www.data.go.kr/data/15053635/fileData.do
- 공공누리 제1유형은 출처표시 조건으로 상업·비상업 이용과 2차적 저작물 작성을
  허용한다. AI유형은 직접 인용 시 출처표시 기술 조치와 동일·실질 유사 산출 방지 등을
  요구한다: https://www.kogl.or.kr/info/license.do
- 삼국사기 시연본은 4,622건, 393,856자이며 1,536차원 벡터 원시 크기는 약 27.08MiB다.
- 실제 토큰 수는 외부 호출 없이 확정하지 않았다. 약 40만~100만 입력 토큰으로 보수
  추정하면 `text-embedding-3-small`의 공개 단가 $0.02/백만 토큰 기준 1회 임베딩 비용은
  약 $0.008~$0.020이다.
- 실질문 1건은 질의 변환·리랭킹·생성·검증 호출을 합쳐 대략 $0.01 미만으로 예상하지만,
  실제 입력 길이와 계정의 처리 등급에 따라 달라질 수 있다. 기본 모델은 교안 예제와 같은
  `gpt-6-luna`로 맞췄다.
- Pinecone Starter 무료 포함량 안에서는 별도 과금이 없을 수 있으나 계정 플랜과 현재
  사용량은 실제 API 확인 전 확정할 수 없다.
- 46개 권한 대장은 `reports/rights_registry_20261114.json`에 기록했다. 삼국사기 1개만
  공식 근거 확인 완료이며, 나머지 45개는 확인 전 외부 전송 금지 상태다.
