# 14종 사료 업로드 최종 점검 — text-embedding-3-large (2026-11-14)

## 최종 결론

- 임베딩 기본 모델을 `text-embedding-3-large`, 기본 차원을 3,072로 변경했다.
- 문서와 질문 임베딩에 모두 `dimensions=3072`를 명시했고 Pinecone 인덱스도 3,072차원과
  cosine인지 적재 전에 검사한다.
- 기존 67,357문서 시연본 중 공식 원문과 대조하지 않은 실록 확장한자 복원 문서 1건을
  제외했다. 67,356개 원문 기사를 7,000토큰 이하로 청킹한 최종 시연본은 68,149벡터이다.
- 전체본에서는 같은 실록 문서 45건을 제외하면 598,208개 원문 기사, 600,820벡터가 된다.
- 실제 OpenAI/Pinecone API 호출, 인덱스 생성, 업로드는 하지 않았다.

`(인공지능 학습용)`이다. 제1유형에 따라 상업·비상업 이용과 변경이 가능하되 출처표시가

## 적용 의무

- Streamlit 결과마다 제공기관, 자료명, 공공누리 제1유형, 공식 상세 URL을 표시한다.
- 직접 인용은 검색된 원문 범위로 제한하고 문헌·기사 ID·기사별 원출처가 있으면 함께 표시한다.
- AI 학습용 표시의 목적에 맞게 임베딩·검색·근거 생성에 사용하되, 사료에서 만든 학습데이터를
  별도 상품처럼 재판매하지 않는다.
- 인물·외교문서 등 제3자 권리가 개입할 수 있는 자료는 원문 전체 재배포보다 검색 결과의 필요한
  범위만 인용한다.

## 무결성과 입력 길이

- 14종 전체에서 전역 문서 ID 중복, 빈 본문, UTF-8 대체문자, 권한 URL 불일치가 0건이다.
- 8,192토큰을 넘는 원문 기사가 1,241건, 최대 104,484토큰이었다. 그대로 API에 보내면 실패한다.
- 기존 기사·메타데이터를 유지하면서 초과 문서만 7,000토큰 이하로 분할한다. 청크 ID는
  `dataset_key:article_id__chunk_NNNN`, 원 기사 ID는 `parent_article_id`로 보존한다.
- 실록 XML의 잘못 직렬화된 surrogate 참조를 메모리에서 결합한 45건은 공식 웹 원문 대조 전
  적재 차단 대상으로 지정했다. 시연 표본에는 1건이 있었고 최종 시연본에서 제외했다.

## 정확한 임베딩 비용

공식 `cl100k_base` tokenizer로 현재 코드가 실제 전송하는 `text` 필드를 계산했다. 단가는
`text-embedding-3-large` 100만 입력 토큰당 USD 0.13이다.

| 범위 | 원문 기사 | 최종 벡터 | 토큰 | OpenAI 비용 |
|---|---:|---:|---:|---:|
| 종전 시연본 | 67,357 | 청킹 전 | 32,970,530 | USD 4.2862 |
| 권장 최종 시연본 | 67,356 | 68,149 | 33,179,450 | USD 4.3133 |
| 전체 안전 범위 | 598,208 | 600,820 | 207,698,410 | USD 27.0008 |

질문 임베딩 비용과 LLM 생성·검증 비용은 사용 횟수에 따라 별도이며 위 표에는 포함하지 않았다.

## Pinecone 용량과 비용

- 시연본의 3,072차원 float32 벡터와 로컬 JSON 메타데이터 합계 추정치는 약 0.91GiB이다.
- 전체 안전 범위의 같은 추정치는 약 7.84GiB이다. 실제 Pinecone 내부 인덱스 오버헤드는 별도다.
- Pinecone 공개 Starter 기준은 저장공간 2GB, 월 2M write units, 월 1M read units이다. 따라서
  시연본은 Starter 후보이나 전체본은 Starter에 들어가지 않는다.
- 공개 Builder는 월 USD 20, 저장공간 10GB이다. 전체 원시 추정치는 들어가지만 인덱스 오버헤드
  여유가 작으므로 전체본은 Standard 또는 실제 Builder 적재 시험·사용량 확인 후 진행해야 한다.
- Standard는 월 USD 50 최소 사용료이며 사용량 기반 과금이다. 공개 on-demand 예시는 저장공간
  약 USD 0.33/GB·월, write units는 cloud/region에 따라 100만당 약 USD 4~4.50이다.

현재 계정의 실제 플랜·기존 인덱스 차원·잔여 사용량은 Pinecone 콘솔 읽기 접근이 승인되지 않아
확인하지 못했다. Pinecone API도 사용자 지시대로 호출하지 않았다. 기존 인덱스가 1,536차원이면
차원은 변경할 수 없으므로 별도의 3,072차원 인덱스가 필요하다.

## 권장 적재 범위

1. 먼저 `korean_history_demo_v3_large_3072_ready.jsonl` 68,149벡터를 단일 namespace
   `korean-history-v1`에 적재한다.
2. 고대·고려·조선·근현대 14종이 모두 포함되어 시대 범위를 유지한다.
3. 검색 품질과 Pinecone 실제 사용량을 확인한 뒤 전체 600,820벡터로 확장한다.
4. 결정적 ID upsert로 재실행 중복을 막고 `dataset_key`, `literature`, `era`, `article_id`,
   `source_url`, 권한 필드로 출처를 추적한다.
