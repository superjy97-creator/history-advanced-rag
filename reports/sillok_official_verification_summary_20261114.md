## 대조 방법과 근거

각 기사마다 다음 조건을 모두 실제 공식 페이지 응답에서 확인했다.

1. `https://sillok.history.go.kr/id/{공식 기사 ID}`가 HTTP 200으로 응답
2. 공식 페이지 내부 기사 ID가 변환된 ID와 일치
3. XML의 날짜와 공식 페이지의 왕대 날짜가 일치
4. 복원 문자 앞뒤 20자 원문 문맥이 공식 페이지 원문에 일치
5. 공식 페이지에 `李𥘼`가 실제 표시됨

기사별 기사 ID, 날짜, 배포본 제목, XML 파일, 공식 URL, 49개 문맥별 일치 여부, 공식 페이지
응답 SHA-256은 `sillok_character_verification_20261114_v2.json`에 기록했다. 배포본 제목과
현재 공식 사이트의 편집 제목이 완전히 같은 것은 35건이고, 문구·구두점이 달라 완전 일치하지
않은 것은 10건이다. 이 10건도 기사 ID·날짜·해당 한자의 원문 문맥은 모두 일치했으며,
배포본 제목은 원본 메타데이터 보존을 위해 임의 변경하지 않았다.
