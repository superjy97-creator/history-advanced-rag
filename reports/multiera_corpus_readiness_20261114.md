## 공통 형식과 중복 방지

모든 문서는 `dataset`, `dataset_key`, `literature`, `era`, `article_id`, `document_type`,
`provider`, `source_url`, 라이선스·AI 표시·권한 근거 URL을 가진다. Pinecone ID는
`dataset_key:article_id`로 결정되므로 같은 입력을 재실행하면 새 벡터가 늘지 않고 같은 ID가
갱신된다. 공통 namespace 기본값은 `korean-history-v1`이며 시대·문헌 메타데이터 필터 검색을
지원한다.

## 이용권한 적용과 제외

포함 자료는 공공데이터포털 개별 상세 페이지에서 공공누리 제1유형과 AI 활용 표시를 직접
확인한 항목이다. 외부 OpenAI/Pinecone 사용은 특정 사업자명이 명시된 허용이 아니라 해당
조건에 따른 해석이므로 `조건부 허용`을 유지한다. 직접 인용 시 제공기관·자료명·라이선스·공식
URL을 표시해야 한다.

다음은 이번 적재에서 보류했다.

- 고려사절요·원고려기사·한국독립운동사자료 원문: 개별 외부 이용 근거 미확정
- 삼일운동 출처정보·탄압기구·근현대인물 CSV: 본문 사료보다 메타데이터 성격이 강함
- 조선소요사건관계서류: 권한 대장과 실제 배포본 표시의 불일치

## 비용 추정

`text-embedding-3-small` 공식 단가는 100만 입력 토큰당 USD 0.02이다. 로컬 tokenizer 데이터가
설치되어 있지 않고 이를 받기 위한 네트워크 접근도 차단되어, API 호출 없이 정확 토큰 수를
확정할 수 없었다. 한국어·한자 본문을 문자당 약 1~2토큰으로 잡은 사전 예산 범위는 다음과 같다.

- 시연 권장 67,357문서: 약 2,704만~5,408만 토큰, USD 0.54~1.08
- 전체 598,253문서: 약 1억 5,938만~3억 1,877만 토큰, USD 3.19~6.38

청킹 제목·메타데이터를 임베딩 본문에 합치면 실제 비용은 위 범위보다 조금 늘 수 있다.
Pinecone 요금은 계정 플랜·클라우드·저장량에 따라 별도이므로 업로드 승인 전 콘솔의 현재
플랜과 한도를 확인해야 한다.

## 검증 한계

- XML 원본 보존, UTF-8 디코딩, 구조 파싱, 기사 ID와 본문 무결성은 확인했다.
- 실록의 잘못 직렬화된 surrogate 숫자 참조는 원본을 고치지 않고 파싱 시에만 유니코드 확장
  한자로 결합했다.
- 각 기사 전체를 공식 웹 화면과 사람 눈으로 대조하지 않았으므로 `공식 원문 대조 완료`로
  표시하지 않는다.
- OpenAI API 호출과 Pinecone 업로드는 수행하지 않았다.
