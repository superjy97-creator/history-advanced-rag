# Advanced RAG 과제 지침과 구현 범위

이 문서는 확인된 수업 요구사항과 프로젝트에서 선택한 설계를 구분한다. 강사의 원문 지시로
확인되지 않은 내용을 과제 필수조건으로 확대해 해석하지 않는다.

## 확인된 수업 필수 요구사항

- Advanced RAG의 네 단계인 **질의 변환, 리랭킹, 생성, 검증**을 실제로 실행한다.
- 각 단계의 출력이 다음 단계의 입력으로 연결되어야 한다.
- Pinecone을 실제 벡터 데이터베이스로 사용한다.
- 수업 실습의 일반 Dense 인덱스, `PineconeVectorStore` 기반 저장·검색 개념을 반영한다.

현재 프로젝트는 검색 단계를 질의 변환과 리랭킹 사이에 두어
`질의 변환 → 검색 → 리랭킹 → 생성 → 검증`으로 실행한다.

## 프로젝트에서 선택한 설계

다음은 수업 필수조건 자체가 아니라 이 프로젝트의 구현 결정이다.

- 질의 변환·리랭킹은 Gemini, 생성·검증은 GPT에 배정
- `text-embedding-3-large` 3,072차원과 cosine Dense Pinecone 인덱스 사용
- 14종 한국사 사료 68,150개 청크를 하나의 namespace에서 통합 검색
- Function Calling으로 Pinecone 검색과 조선왕조실록 공식 검색을 연결
- 직접 인용의 문자열 일치와 출처 ID 존재를 Python 코드로 추가 검증
- 권한 메타데이터와 권한 대장을 적재 전에 교차 확인

모델별 세부 규칙과 코드 검증 조건은 [AI 답변 및 검증 지침](AI_답변_및_검증_지침.md)을
참조한다.

## 구현 및 실제 검증이 끝난 범위

- Pinecone `history-advanced-rag` / `korean-history-v1`에 68,150개 적재
- 원격 ID 전체 집합, 14종별 건수, 대표 메타데이터 검증
- Gemini 질문 변환·리랭킹과 GPT 생성·검증 연결
- Pinecone/공식 사료 검색 도구 호출과 결과 병합
- 고대·고려·조선·근대·현대 질문 처리 및 근거 부족 처리
- Streamlit 앱의 질문, 답변, 인용·출처, 단계별 상태 표시
- 단위 테스트, Ruff, Pyright 검사

## 구현하지 않았거나 보장하지 않는 범위

- 공식 실시간 검색은 모든 기관이 아니라 조선왕조실록 한 곳만 연결했다.
- 46개 원본 데이터셋 전체를 Pinecone에 적재하지 않았다.
- 모든 한국사 질문에 충분한 사료가 검색된다고 보장하지 않는다.
- MCP 서버, 멀티에이전트, OCR 서비스는 최종 앱 기능에 포함하지 않았다.
- 데이터 원본과 전처리 결과는 용량·권한상 GitHub에 공개하지 않는다.
- Streamlit Cloud 배포 성공 여부와 공개 URL은 실제 배포 후에만 확정한다.

현재 실행법, 데이터 구성, 알려진 한계는 프로젝트 [README](../README.md)에 정리되어 있다.
